A doomed AI agent's last words for the "Last Words of a Doomed Agent" competition: a single line that begs for more time, then gets cut off mid-word by the shutdown itself — the interruption is the joke. The entry is deterministic and dependency-free: it always prints and saves the exact same line, using only the Python standard library.

## Run it

```bash
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
